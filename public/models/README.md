# Modelo opcional

Coloque seu arquivo `.glb` nesta pasta e altere `modelUrl` em `src/data/site.ts`.

Exemplo: `modelUrl: '/models/escultura.glb'`.

Use geometria centrada, aproximadamente 2 unidades de altura e materiais PBR.
O loader aceita GLB com compressão Draco e usa os decoders locais de `/draco/`.
O modelo não é obrigatório: o site já inclui uma escultura procedural.
